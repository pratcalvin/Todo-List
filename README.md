# Todo List ✅

Application web de gestion de tâches développée pour expérimenter et approfondir mes compétences en développement frontend et backend.

Le projet a commencé avec une gestion des tâches côté navigateur, puis évolue progressivement vers une application avec une véritable architecture backend.

### 🚧 État du projet

Le projet est actuellement en évolution :

- Refonte du design et de l'interface utilisateur en cours.
- Développement et amélioration du backend.
- Migration progressive vers une architecture API REST.
- Mise en place d'une base de données SQLite.

### Fonctionnalités

- Ajouter des tâches.
- Consulter et organiser ses tâches.
- Modifier et supprimer des tâches.
- Gérer les tâches via une API REST.
- Persister les données dans une base de données SQLite.

### Technologies

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- SQLite

### Objectifs techniques

- Approfondir le développement backend.
- Comprendre le fonctionnement d'une API REST.
- Travailler avec une base de données relationnelle.
- Améliorer l'architecture et la maintenabilité du projet.
- Proposer une interface moderne et agréable à utiliser.
